# Login & Registration Page (HTML + CSS)

## 📌 Project Overview
This project is a **modern Login and Registration UI** built using **advanced HTML5 and CSS3**.  
It focuses on **clean design, responsiveness, and modern CSS properties** without using JavaScript or backend logic.

---

## ✨ Features
- Responsive design (mobile & desktop)
- Flexbox-based layout
- CSS gradients
- Floating label inputs
- Smooth transitions & hover effects
- Media queries for smaller screens
- Clean and modern UI

---

## 🛠️ Technologies Used
- **HTML5**
- **CSS3**
  - Flexbox
  - Media Queries
  - Transitions
  - Linear Gradients
  - Box Shadow
  - Border Radius

## 📱 Responsive Design
The layout adjusts automatically using this media query:
```css
**@media (max-width: 768px) {
  .container {
    flex-direction: column;
    width: 90%;
  }
}
Desktop: Side-by-side layout
Mobile: Stacked layout
